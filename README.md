# Credit PD Scorecard
A credit PD scoring model built for IFRS 9, using logistic regression and scorecard transformation.

## Overview
- Data preprocessing: WOE binning, IV feature selection
- Model: Logistic regression
- Output: Standard credit scorecard
- Tech: Python, pandas, numpy, scikit-learn
